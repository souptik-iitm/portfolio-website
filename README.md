# Souptik Pramanik | Data Science & AI Portfolio

Welcome to the repository for my personal portfolio website. This project serves as a digital hub for my software engineering projects, machine learning pipelines, and technical experiments. It is designed with a modern, dark-mode "bento-box" aesthetic, emphasizing clean architecture and a highly responsive user interface.

🌍 **Live Website:** [souptikpramanik.vercel.app](https://souptikpramanik.vercel.app)

## 🛠️ Tech Stack
This project was engineered using modern web technologies to ensure speed, scalability, and maintainability:
* **Framework:** Next.js (App Router)
* **Styling:** Tailwind CSS (v4) with custom glassmorphism utilities
* **Language:** TypeScript
* **Icons:** Lucide-React & React-Icons
* **Deployment:** Vercel

## ✨ Key Features
* **Modern Aesthetic:** Custom CSS grid implementation featuring a sleek "bento-box" layout and subtle gradient backdrops.
* **Responsive Design:** Fully optimized for mobile, tablet, and desktop viewing experiences.
* **Centralized Data Management:** Portfolio content (projects, skills, bio) is decoupled from the UI components via a structured data file (`portfolioData.ts`) for effortless future updates.
* **Direct Messaging:** Integrated Web3Forms contact form for seamless professional outreach without needing a backend server.
